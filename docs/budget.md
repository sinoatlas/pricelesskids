# 从出生到大学毕业：预算怎么做

这里的每个金额都是**编辑自拟教学输入**，没有价格调查依据，不代表江苏平均、最低、推荐消费或未来必然支出。真实价格必须换成家庭所在市县、学校、孩子需求和当年报价。

同样的健康与教育需要可以由不同家庭分工满足；本表不定义“穷养”“富养”或孩子应有的身价。

## 一组能重算的示例

假设：常见公办教育路径、家庭照护、未加入付费托育、常见四年本科；大学阶段示例把食堂餐费等全年生活支出计入，不再额外加同口径家长转账。用2026不变价格、0%增长率，出生一次性新增用品5000元，住房增量与机会成本暂记0，所有补贴暂记0以免假设资格。

| 阶段 | 年数 | 自拟年支出 | 阶段合计 |
| --- | --- | --- | --- |
| 0—3岁 | 3 | 16000元 | 48000元 |
| 3—6岁 | 3 | 18000元 | 54000元 |
| 小学 | 6 | 15000元 | 90000元 |
| 初中 | 3 | 18000元 | 54000元 |
| 高中 | 3 | 24000元 | 72000元 |
| 大学 | 4 | 30000元 | 120000元 |
| 出生一次性 | 一次 | 5000元 | 5000元 |
| **22年直接支出** | **22** | — | **443000元** |

**443000元只是这组输入的加法结果。** 未含母亲分娩医疗费用、新增住房、家庭照护机会成本、重大医疗事件、婚嫁买房、出国留学、毕业后继续就学与投资损益。表中的健康费用是占位输入，不暗示重大医疗可被该金额覆盖。

年度拆分在[data/budget.example.json](../data/budget.example.json)：食物、用品、衣物交通、健康、教育照护、可选项目。大学教育照护6500元为任意占位数，不是江苏公办高校统一学费；幼儿园6000元同样不是报价，应把减免后的实际年度园费填写进去。

0—3岁示例假设配方/食物年8000元。母乳或混合家庭自行替换，另计照护工时；不把这个输入用于判断喂养方式。幼儿園伙食和大学食堂餐费若已包含food，education_care只填非餐费部分，避免重复。

## 三种变化怎样计算

| 自拟变化 | 计算 | 结果 / 解释 |
| --- | --- | --- |
| 原输入 | 直接支出 | 443000元 |
| 增加两年付费托育，每月2000元，全年12月 | 443000 + 2000×12×2 | 491000元；托育报价和实际月份须改成家庭实价 |
| 每年增加住房现金支出12000元、持续22年 | 443000 + 12000×22 | 707000元；不等于购房资产净损失 |
| 一位照护者减少两年工作，净收入差30000元/年 | 443000 + 30000×2 | 503000元经济成本示例；不是同额现金消费 |

贷款是融资不是补贴；储蓄是资金安排不是消费，不能本金加一次、支付学费再加一次。住房可同时看现金流与资产变化，不能全额房价既计资产又计不可回收育儿成本。

## 通胀与年度滚动

运行：

```console
python tools/budget.py
python tools/budget.py path/to/private-family-budget.json
```

模型按年龄年索引计算：每年该阶段基准支出 × (1 + 假设增长率)^年龄年；出生一次性单列。默认同时显示0%、2%、4%的敏感性情景，**不是通胀预测或投资建议**。大学从第18年开始加权，不能把22年总额简单乘一次增长率。

保持示例不变时，基准年2026、出生年也视为2026；已有较大孩子的家庭要改剩余年限和起算口径，不能照搬模型把已发生支出再算一次。每年更新真实费用与剩余计划优于一次推22年。

## 补贴如何扣除

实际确认的现金补贴填benefits_total。育儿补贴按孩子出生月份及申领资格算实际金额，不统一预扣10800元。个税专项扣除只能扣**实际减少的税额**，不是扣除额24000元/年。学前减免若已用于填写实际园费，不能再从总额扣第二次。助学贷款不填benefits_total。

机会成本字段annual_opportunity_cost默认对应每年同样数额；只减少工作两年的，请用逐年私有记录或单列一次性调整，不能填进去让模型错误乘22年。大额应急情况用单独应急预案处理，不假设平均医疗占位可覆盖。

家庭真实预算、收入和孩子个人资料保存在仓库以外的私有文件；本项目不需要这些数据。注意不要把私有JSON一起上传公共仓库。
