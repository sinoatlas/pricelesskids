# 编写、证据与核验方法

核验日期：2026-10-10。范围：江苏家庭从孩子出生到大学毕业的照护、教育、健康、安全、支出和办事。大学采用常见四年本科阶段示例，未把所有特殊学制、每个县区和每一种疾病都完整列尽。

## “认真核验”不等于机构认证

这是独立调研与原创总结，没有政府、医院、教育部门或原参考项目的认证、背书或逐条专家审稿。政策以办理当时有权机关的文件和实际审核为准；医疗条目用于识别可靠信息和服务，不替代诊疗。

## 两个维度，分别看

| 依据类型 | 表示什么 | 不能推出什么 |
| --- | --- | --- |
| P · 政策 / 法律 / 官方执行解释 | 某机构在特定日期、区域、对象下规定或解释了某件事 | 不保证申请人合格，也不证明某学习方法有效 |
| G · 权威指南 / 专业机构建议 | 对明确人群的公共健康或临床方向建议 | 不保证每个孩子获同样效果，不替代个体评估 |
| R · 原始研究 | 在研究对象、设计和环境下测得的结果 | 不直接推广成江苏所有家庭收益；须看设计、偏倚和绝对量 |
| J · 编辑判断 / 计算框架 | 原创生活安排、比较方法、时间估计和预算输入 | 不伪装为实验结论或官方标准 |
| U · 待核 | 有线索但没找到足够原文、最新规则或全部条件 | 不作为确定性资格和支出依据 |

P+J、G+J表示依据支持部分事实，具体清单和实施安排由编辑组织。论文S37目前仅核题录与研究设计，未完整提取统计结果，正文不使用其效应数值作承诺。

优先级“极高 / 高 / 中”为编辑判断：安全、及时就医、医疗保障和不可逆截止错误优先；其后是基本生活和长期能力；再后是可选消费。同档不排序，不用任意百分比把安全、金钱和成绩加成一个分数。“零新增支出”不意味着没有照护工时、已有设备或交通成本。

## 来源选择与核验步骤

1. 优先国家法律政策、江苏省主管部门、市县教育医保等部门、WHO及专业机构；需要效果数字时查原始论文。
2. 记录链接、发布者、页面日期、地域、人群、条款要点和本次阅读状态。页面发布日期、政策生效日、事件发生日不同，不混用。
3. 区分成功打开原站正文、检索工具提供的官方正文、只读标题/摘要、媒体线索和未核附件。不能把所有状态合称“官方原文已完整验证”。
4. 优先查看新旧冲突：个税旧1000元标准、旧生育保险条件、学前一年减免、2026助学贷款与求职补贴、新增免疫规划HPV均做更新提示。
5. 解释资格、地域、例外和下一步办事；不从“鼓励”“推动”“可探索”推导个人必然能领。
6. 价格不足时留待填写；没有用购物平台报价冒充全省平均价，没有用历史中考线或学区营销预测孩子结果。

## 更新约定

招生年度前、秋季医保缴费前、开学收费前和政策变更后优先核验动态条目。更新时写明新文件、条款变化、覆盖对象与核验日期；失效来源保留历史说明或替代链接，不直接删掉例外。

新增医学效果数字须同时写人群、比较组、观察期、绝对差、相对差和不确定性；无法核对就不报数字。编辑时间估计保留“编辑估计”，预算敏感性保留“自拟情景”。

## 本地检查做什么

`python tools/check.py` 检查编号、字段、来源映射、城市覆盖、本地链接与预算算术。它不会访问原站，不证明政策仍现行、证据正确、页面在线或专家审稿完成。链接可点击也不等于条款适用于你的家庭。
