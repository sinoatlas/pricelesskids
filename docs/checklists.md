# 分阶段办事清单

以下是编辑整理的流程表，具体资格回到[正文](complete-guide.md)与[来源](sources.md)。日期按实际出生和入学年填写，不用2026例子自动推下一年。

## 出生与0—3岁

- [ ] 出院记录、筛查结果与复查日期已收到；异常追踪有负责联系人。
- [ ] 出生医学证明信息正确，落户与接种建档要求已问清。
- [ ] 新生儿医保90天内登记与缴费到账，确认所缴年度和出生当年报销规则。
- [ ] 育儿补贴资格、首次申请、续领与户籍地申领窗口已确认。
- [ ] 个税照护扣除父母分配一致；3岁起按条件转子女教育扣除。
- [ ] 社区儿童保健档案及下次预约已安排。
- [ ] 安全睡眠、乘车、洗澡看护和家庭危险物排查完成。
- [ ] 家庭照护分工、备用照护者和夜间急诊路线明确。

## 幼儿园与小学前一年

- [ ] 园所资质/普惠身份、全项收费、减免、退费与接送已核。
- [ ] 学前一年保教费减免明确，未把伙食等费用算成免除。
- [ ] 本区县当年小学年龄、房户居住/随迁条件与材料截止已记录。
- [ ] 学籍、产权、居住证与就业材料按所属路径核对；不确定向教育局咨询。
- [ ] 报名、补件、复核和通知书节点有提醒。
- [ ] 生活自理、睡眠、语言表达和适应支持有安排。

## 小学与初中

- [ ] 视力屈光、口腔、睡眠、活动及情绪问题得到必要支持。
- [ ] 学校课后服务、外部托管和交接责任明确。
- [ ] 本市中考科目、总分、考试安排、体育和志愿规则查到原文。
- [ ] 初中指标/分配生资格和拟转学影响已核清。
- [ ] 选择兴趣培训看资质、适配和合同，预付不超监管范围。
- [ ] 困难认定与资助窗口已向学校确认。

## 高中与大学入学

- [ ] 选科查对应高考年份、目标院校专业要求。
- [ ] 高考报名、随迁资格、合格考、体检、特殊类型和缴费分别确认。
- [ ] 逐志愿核学校专业组、调剂、体检、校区、学费和特殊项目义务。
- [ ] 正式提交后留存成功结果，考生保管账号与验证方式。
- [ ] 录取及征求志愿通过官方查询，未付“内部名额费”。
- [ ] 必要时申请绿色通道和助学贷款；贷款不算补贴收入。
- [ ] 新学校医保与原居民医保接续已确认。

## 大学与毕业

- [ ] 每学年资助认定、续贷、医保及收费变化已核对。
- [ ] 学习与实践安排、月度预算和家庭应急渠道明确。
- [ ] 求职补贴资格与毕业学年申请窗口已查。
- [ ] 就业协议/合同薪酬、地点、工时、社保和约束已读。
- [ ] 毕业、学位、档案、户口、团党关系与贷款去向有记录。
- [ ] 毕业后医保起止、单位参保或居民参保已衔接。
