### 09-01 · 选科先查目标专业要求

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 15—16岁 |
| 怎么做 | 从省考试院当届专业选科要求和院校章程确认可报组合；同时评估兴趣、基础、课程资源与成绩表现。 |
| 金钱成本 | 官方查询可免费 |
| 时间与精力 | 选科前比较并复核 |
| 主要收益 | 避免选科组合挡住目标专业 |
| 适用条件 | 普通高中选科学生 |
| 依据类型 | J：编辑决策流程 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 不以一句“物化生最划算”代替个体选择；以对应高考年份要求为准。 |
| 核验日期 | 2026-10-10 |
