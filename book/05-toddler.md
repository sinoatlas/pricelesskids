# 1—3岁：早期发展和托育

以回应、游戏、生活自理和稳定照护为主，任何早教消费都应说明孩子实际需要。

[返回目录](../README.md) · [核验方法](../docs/methodology.md) · [来源台账](../docs/sources.md)

<a id="05-01"></a>

### 05-01 · 亲子交流融入日常

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—3岁 |
| 怎么做 | 做饭、散步和穿衣时与孩子交流，回应其手势和声音；使用已有图书、讲故事和游戏。 |
| 金钱成本 | 可零新增支出 |
| 时间与精力 | 日常分散进行 |
| 主要收益 | 增加早期学习机会 |
| 适用条件 | 婴幼儿家庭 |
| 依据类型 | G+J：官方早期发展指南，安排为编辑建议 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

- [S12: 婴幼儿早期发展服务指南（试行）](https://www.nhc.gov.cn/fys/c100078/202502/19c9c6dee0274d23822f313a99ae1779.shtml) — 官方检索正文已读；适用范围：婴幼儿及养育人。

### 05-03 · 托育比较备案、安全和接送

### 05-04 · 家庭照护也计算工时

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—3岁 |
| 怎么做 | 祖辈照护先协商健康负担、作息、安全和替班；一方离职方案算工资、社保、职业恢复与休息成本。 |
| 金钱成本 | 不以零现金视为零成本 |
| 时间与精力 | 一次家庭会议及定期调整 |
| 主要收益 | 避免隐形成本集中在一人 |
| 适用条件 | 有祖辈或家庭全职照护者 |
| 依据类型 | J：家庭决策方法 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

依据：本项目原创决策建议，无直接效果研究；不包装为循证结论。

<a id="05-05"></a>

### 05-05 · 不用屏幕替代低龄照护

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—3岁 |
| 怎么做 | 用陪伴、游戏与安全探索替代手机哄娃；国家近视核心知识建议0—3岁不使用视屏电子产品。 |
| 金钱成本 | 可零新增支出 |
| 时间与精力 | 需要照护者时间 |
| 主要收益 | 减少过早持续近距离视屏 |
| 适用条件 | 一般婴幼儿 |
| 依据类型 | G：官方健康建议 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 视频医疗或特定辅助沟通需求由专业人员评估；不羞辱已经使用屏幕的家庭。 |
| 核验日期 | 2026-10-10 |

- [S16: 防控儿童青少年近视核心知识十条](https://www.nhc.gov.cn/fys/c100078/202307/a210193cfd774009a1db0399d713fec9.shtml) — 官方检索正文已读；适用范围：儿童青少年。
