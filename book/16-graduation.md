# 毕业前后：求职、手续和保障接续

范围止于顺利从学校进入社会。不同学制、升学、就业或暂未就业需要不同办事路径。

### 16-01 · 困难毕业生检查求职补贴窗口

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 毕业学年 |
| 怎么做 | 江苏省内符合条件的困难毕业生，按2026新通知在9月1—30日或5月1—31日通过智慧人社等申请1500元/人一次性求职补贴。 |
| 金钱成本 | 不找收费代办 |
| 时间与精力 | 申报及学校审核 |
| 主要收益 | 取得符合资格的求职支持 |
| 适用条件 | 通知所列院校全日制非定向困难毕业生，不限户籍 |
| 依据类型 | P：2026人社通知 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 符合低保、零就业/农村零转移家庭、符合条件孤儿/事实无人抚养儿童、持证残疾、毕业学年国家助学贷款或特困等条件之一；每人一次，身份重叠不重复领。 |
| 核验日期 | 2026-10-10 |

- [S32: 关于做好一次性求职补贴发放工作的通知](https://jshrss.jiangsu.gov.cn/art/2026/8/26/art_77276_11820813.html) — 官方正文已读；适用范围：江苏省内相关院校困难毕业生，不限户籍。

### 16-02 · 招聘先收费先停下来核实

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 大学及毕业 |
| 怎么做 | 核公司主体与合同；遇押金、扣证、培训贷或提供银行卡账户等要求先停止并核实，保留证据。 |
| 金钱成本 | 避免先付不明费用 |
| 时间与精力 | 核主体及条款 |
| 主要收益 | 降低求职诈骗和财务风险 |
| 适用条件 | 求职者 |
| 依据类型 | P+J：人社部求职提示 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

- [S33: 高校毕业生求职提示：严防四类陷阱](https://app.www.gov.cn/govdata/gov/202405/22/515248/article.html) — 官方检索正文已读；适用范围：求职者。

### 16-03 · 签约前看岗位与约束

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 毕业前后 |
| 怎么做 | 分别阅读就业协议和劳动合同，确认薪资、地点、试用期、工时、社保及违约；重大疑问向学校就业中心或法律服务咨询。 |
| 金钱成本 | 咨询按实际 |
| 时间与精力 | 签约前逐项阅读 |
| 主要收益 | 减少误签和信息不对称 |
| 适用条件 | 签约毕业生 |
| 依据类型 | J：核查建议 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 两类协议效力不能简单等同；本指南不据具体合同作法律结论。 |
| 核验日期 | 2026-10-10 |

- [S33: 高校毕业生求职提示：严防四类陷阱](https://app.www.gov.cn/govdata/gov/202405/22/515248/article.html) — 官方检索正文已读；适用范围：求职者。

### 16-04 · 毕业医保不留空窗

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 毕业前后 |
| 怎么做 | 问学校参保待遇何时结束，已就业者核单位参保；未就业或升学者按身份转换核居民医保及新校衔接，保存到账记录。 |
| 金钱成本 | 新参保地标准 |
| 时间与精力 | 毕业前规划与到期核对 |
| 主要收益 | 减少疾病支出暴露 |
| 适用条件 | 毕业生 |
| 依据类型 | P+J：省医保衔接规则 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 省政策对符合身份转换情形在90天内参保缴费有等待期规则；不是所有断保都免等待期。 |
| 核验日期 | 2026-10-10 |

- [S02: 江苏省贯彻落实基本医疗保险参保长效机制的若干举措](https://ybj.jiangsu.gov.cn/art/2025/6/30/art_74036_11604136.html) — 官方正文已读；适用范围：江苏居民医保。

### 16-05 · 学籍学历、档案和贷款分别交接

| 字段 | 内容 |
| --- | --- |

| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
