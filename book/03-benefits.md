# 补贴、休假、税费和救助

金额要区分现金补贴、报销、免收费、税前扣除和贷款；五者不能直接相加当收入。

### 03-01 · 通过户籍地申领育儿补贴

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—3岁 |
| 怎么做 | 符合条件的江苏户籍婴幼儿按年度申请每孩每年3600元；用国家系统或户籍地乡镇街道窗口，留存受理信息。 |
| 金钱成本 | 申请无需购买代办服务 |
| 时间与精力 | 材料齐全后按平台办理 |
| 主要收益 | 取得符合资格的补贴 |
| 适用条件 | 符合法律法规生育且江苏户籍、未满3周岁 |
| 依据类型 | P：省方案 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 2025年前出生且未满3岁按应补贴月份折算。首次申请、续领和截止期办理前确认，不许诺所有孩子均获10800元。 |
| 核验日期 | 2026-10-10 |

- [S01: 江苏省育儿补贴制度实施方案](https://www.wxbh.gov.cn/doc/2026/02/27/4761455.shtml) — 官方正文已读；适用范围：江苏户籍、符合规定的3周岁以下婴幼儿。

### 03-02 · 婴幼儿照护与子女教育扣除接续

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 出生至符合学历教育期间 |
| 怎么做 | 个税App按实际年龄和学段填报：婴幼儿照护或子女教育每孩每月2000元；父母协商一方100%或双方各50%。 |
| 金钱成本 | 0元申报 |
| 时间与精力 | 每年核对家庭分配 |
| 主要收益 | 有应纳税额时减少税负 |
| 适用条件 | 符合税法规定纳税人 |
| 依据类型 | P：税务政策 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 2000元是税前扣除，不是每月到账。实际节税取决于税率和应纳税额；不能双方各填2000元。 |
| 核验日期 | 2026-10-10 |

- [S04: 提高专项附加扣除标准十问答](https://www.chinatax.gov.cn/chinatax/n810341/n810760/c5211366/content.html) — 官方正文已读；适用范围：全国符合条件的纳税人。

### 03-03 · 产假长度与津贴天数分开问

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 生育与0—3岁 |
| 怎么做 | 向单位确认适用的产假、护理假及育儿假；向医保确认津贴和医疗费用，保存书面答复。省公开答复列158、15及每方每年10天。 |
| 金钱成本 | 无需因咨询购买保险 |
| 时间与精力 | 一次核对，休假前确认 |
| 主要收益 | 使用合法权益、避免误算收入 |
| 适用条件 | 江苏符合规定职工；具体适用条件需复核 |
| 依据类型 | P：官方解释与执行核对 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 历史答复不是对所有雇佣和参保身份的自动保证；产假不直接等于津贴计发天数。 |
| 核验日期 | 2026-10-10 |

- [S10: 对省人大第4006号建议答复](https://wjw.jiangsu.gov.cn/art/2022/8/22/art_59524_10582799.html) — 官方检索正文已读；执行口径办理前复核；适用范围：符合规定江苏职工。
- [S09: 生育支持政策体系若干措施](https://www.jiangsu.gov.cn/art/2025/2/20/art_84418_11496034.html) — 官方检索正文已读；适用范围：江苏。

### 03-04 · 灵活就业者核对生育津贴资格

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 备孕至生育 |
| 怎么做 | 参加江苏职工医保的符合条件人员，查连续足额缴费月数、生育当月状态；连续满12个月才符合该问答津贴条件。 |
| 金钱成本 | 原医保缴费；不凭估算决定参保 |
| 时间与精力 | 一次查询缴费记录 |
| 主要收益 | 避免沿用“灵活就业不能领”的旧说法 |
| 适用条件 | 问答覆盖人员，不含退休者 |
| 依据类型 | P：医保局新问答 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 按98天计发、基数为全省上年社保缴费工资基数下限÷30。医疗费用待遇与津贴条件不同，办理前确认生育日期和政策衔接。 |
| 核验日期 | 2026-10-10 |

- [S03: 灵活就业人员纳入生育保险政策问答](https://ybj.jiangsu.gov.cn/art/2025/12/26/art_73937_11716161.html) — 官方正文已读；适用范围：江苏参加职工医保的符合条件灵活就业人员。

### 03-05 · 经济困难先向学校申请认定

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 幼儿园至大学 |
| 怎么做 | 向学校资助部门问困难认定、助学金、减免、应急补助；按真实情况申报并记录申请窗口。 |
| 金钱成本 | 通常无代办费 |
| 时间与精力 | 开学及家庭变化时 |
| 主要收益 | 获取符合条件的资助 |
| 适用条件 | 困难学生，条件按学段 |
| 依据类型 | P+J：省政策与申请建议 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 资助不等于全额覆盖支出；2025总览的金额须以当前学年学校文件复核。 |
| 核验日期 | 2026-10-10 |

- [S05: 江苏省学生资助政策简介（2025年版）](https://jyt.jiangsu.gov.cn/art/2025/4/29/art_60306_11555460.html) — 官方检索正文可读；年度标准需复核；适用范围：江苏各学段符合条件学生。
- [S06: 2026年国家助学贷款工作指引转发通知](https://jyt.jiangsu.gov.cn/art/2026/5/8/art_58960_11767042.html) — 官方正文已读；适用范围：符合条件本专科及研究生。

### 03-06 · 困境与残障家庭建立部门联系人

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—18岁 |
| 怎么做 | 向乡镇街道、民政、残联、学校分别核实生活保障、康复及融合教育支持，保存申请编号；已有诊断资料留在私有档案。 |
| 金钱成本 | 项目依资格 |
| 时间与精力 | 初次材料整理后持续跟进 |
| 主要收益 | 减少服务断档 |
| 适用条件 | 困难、残障、重病或监护困境家庭 |
| 依据类型 | P+J：分类保障与联系建议 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 不臆测当地每月金额；不同保障可能有衔接或不可重复规定。 |
| 核验日期 | 2026-10-10 |

- [S34: 江苏省困境儿童基本生活精准保障实施办法](https://www.jiangsu.gov.cn/art/2026/4/23/art_64797_11761547.html) — 官方检索正文已读；适用范围：符合困难分类未满18岁儿童。
