# 0—1岁：喂养、睡眠和用品

必要照护先于商品升级。母乳、混合和配方家庭都需要支持，喂养方式不作为家长好坏评价。

<a id="04-01"></a>

### 04-01 · 支持母乳，也支持必要配方

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—6月 |
| 怎么做 | 一般情形WHO推荐前6个月纯母乳；喂养困难、用药、疾病或家庭限制时向医护咨询可持续方案。 |
| 金钱成本 | 家庭实际成本 |
| 时间与精力 | 喂养与照护时间不可忽略 |
| 主要收益 | 满足婴儿营养需要 |
| 适用条件 | 一般婴儿；特殊疾病个体处理 |
| 依据类型 | G：WHO建议 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 不是把母乳描述为零成本，也不以坚持母乳延误医疗或营养支持。 |
| 核验日期 | 2026-10-10 |

- [S13: Infant and young child feeding](https://www.who.int/news-room/fact-sheets/detail/infant-and-young-child-feeding) — 指南机构检索正文已读；适用范围：一般婴幼儿；疾病等需个体评估。

<a id="04-02"></a>

### 04-02 · 配方奶按比例冲调

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—1岁 |
| 怎么做 | 按产品和医护要求量水后加粉，不稀释省钱、不加浓；清洁喂养器具。开始喝后1小时内、配制后2小时内使用，剩奶弃去。 |
| 金钱成本 | 奶粉和清洁成本 |
| 时间与精力 | 每次冲调 |
| 主要收益 | 降低污染及错误配比风险 |
| 适用条件 | 配方喂养家庭 |
| 依据类型 | G：CDC安全建议 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 室温时限不是冷藏时限；高风险婴儿、冲调水温和冷藏按医护与标签要求，粉状配方并非无菌。 |
| 核验日期 | 2026-10-10 |

- [S36: Infant Formula Preparation and Storage](https://www.cdc.gov/infant-toddler-nutrition/formula-feeding/preparation-and-storage.html) — 官方检索正文已读；适用范围：配方喂养；高风险婴儿额外谨慎。

### 04-03 · 约6个月引入适宜辅食

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 约6月起 |
| 怎么做 | 一般从约6个月开始引入安全且营养充足的辅食；看吞咽发育、进食反应，疾病或早产请个体指导。 |
| 金钱成本 | 食材按实际 |
| 时间与精力 | 备餐与陪伴 |
| 主要收益 | 支持生长与逐渐适应家庭食物 |
| 适用条件 | 一般婴儿 |
| 依据类型 | G：WHO建议 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 不把昂贵成品辅食视为必需，也不规定所有婴儿同一天启动。 |
| 核验日期 | 2026-10-10 |

- [S13: Infant and young child feeding](https://www.who.int/news-room/fact-sheets/detail/infant-and-young-child-feeding) — 指南机构检索正文已读；适用范围：一般婴幼儿；疾病等需个体评估。

<a id="04-04"></a>

### 04-04 · 每次睡眠先检查安全环境

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—1岁 |
| 怎么做 | 每次放下时仰卧，使用坚实平坦不倾斜的独立睡眠面；移除枕头、床围、软玩具和松散被褥，同室不同床。 |
| 金钱成本 | 合规睡眠设施成本 |
| 时间与精力 | 每次检查约一分钟，编辑估计 |
| 主要收益 | 降低睡眠相关窒息风险 |
| 适用条件 | 一般健康婴儿 |
| 依据类型 | G：AAP安全睡眠 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 不推荐定型枕、睡眠斜坡或让婴儿在沙发上睡；特殊医疗问题遵医嘱。 |
| 核验日期 | 2026-10-10 |

- [S14: How to Keep Your Sleeping Baby Safe](https://www.healthychildren.org/english/ages-stages/baby/sleep/pages/a-parents-guide-to-safe-sleep.aspx) — 专业机构检索正文已读；适用范围：一般健康婴儿。

### 04-05 · 出生前只购最小可用用品

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—1岁 |
| 怎么做 | 先满足安全睡眠、喂养、清洁、合适衣物和出行；纸尿裤小包试用，尺寸确认后再采购。 |
| 金钱成本 | 按清单报价，不预设品牌 |
| 时间与精力 | 一次列单后按消耗补货 |
| 主要收益 | 减少尺码不合和闲置 |
| 适用条件 | 一般家庭 |
| 依据类型 | J：消费建议 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

依据：本项目原创决策建议，无直接效果研究；不包装为循证结论。

### 04-06 · 不为“睡整觉”承诺长期预付

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—1岁 |
| 怎么做 | 睡眠困难先向儿童保健了解喂养和发育情况；购买照护服务看资质、责任和退费，不依“包睡整夜”判断医学效果。 |
| 金钱成本 | 可先用公卫咨询 |
| 时间与精力 | 按实际问题咨询 |
| 主要收益 | 减少夸大承诺和延误评估 |
| 适用条件 | 睡眠困扰家庭 |
| 依据类型 | J：服务选择建议 |
| 行动优先级 | 中（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

- [S11: 0—6岁儿童健康管理相关提案答复](https://www.nhc.gov.cn/wjw/tia/202112/47fc2eb490804f5abce88f47a7c42d61.shtml) — 官方检索正文已读；适用范围：辖区0—6岁儿童。
