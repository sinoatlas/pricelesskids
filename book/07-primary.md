# 6—12岁：公办教育、学习和课后安排

义务教育入学以当年属地规则为准。优先解决作息、理解和稳定接送，不靠长期预付款购买确定性。

### 07-01 · 查区县细则，不只看市级通知

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 入小学前一年 |
| 怎么做 | 从13市索引找到属地区县当年方案，核对居住、产权、户籍、截止日期、报名与复核；保存原文件。 |
| 金钱成本 | 通常无代办费 |
| 时间与精力 | 招生前核对及补材料 |
| 主要收益 | 减少错报漏报 |
| 适用条件 | 所有入小学或初中家庭 |
| 依据类型 | P+J：地方招生规则 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

### 07-02 · 把入学资格与买房决定分开

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 6—15岁 |
| 怎么做 | 购房前请教育部门确认该地址认定规则、学位占用、产权比例及交付；把房价溢价、交易费和通勤列入预算。 |
| 金钱成本 | 可能涉及重大住房支出 |
| 时间与精力 | 一次书面核对 |
| 主要收益 | 避免以中介承诺当学位保证 |
| 适用条件 | 考虑为入学买房家庭 |
| 依据类型 | P+J：地方学位规则与成本框架 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 不提供房产投资收益预测，不承诺买房即可指定校入学。 |
| 核验日期 | 2026-10-10 |

- [C05: 2026句容义务教育招生工作意见](https://www.jurong.gov.cn/jrjyj/bmwjs/202607/0bd9de328e474b87925e658ad736081d.shtml) — 官方正文已读；适用范围：仅镇江所辖句容。
- [C07: 2026泰州高港区义务教育招生方案](https://www.cmc.gov.cn/zfxxgk/jyj/fdzdgknr/zdly/ywjy/art/2026/art_716cd01114714772a1cf4081f24d4819.html) — 官方正文已读；适用范围：仅医药高新区（高港区）。

### 07-03 · 课后服务先看学校方案

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 6—15岁 |
| 怎么做 | 问学校结束时间、服务内容、收费、减免和晚接安排，再比较校外托管的全年价格和交接责任。 |
| 金钱成本 | 当地学校公示标准 |
| 时间与精力 | 一次咨询及每日接送 |
| 主要收益 | 降低托管和接送负担 |
| 适用条件 | 有课后看护需求家庭 |
| 依据类型 | P+J：省支持政策与选择建议 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

- [S09: 生育支持政策体系若干措施](https://www.jiangsu.gov.cn/art/2025/2/20/art_84418_11496034.html) — 官方检索正文已读；适用范围：江苏。

### 07-06 · 每天保留自主和家务时间

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 6—12岁 |
| 怎么做 | 让孩子参与整理书包、简单家务和选择活动；安排连续可玩时间，遇到困难先支持而非全代办。 |
| 金钱成本 | 可零新增支出 |
| 时间与精力 | 随日常活动 |
| 主要收益 | 培养生活能力并减少替代劳动 |
| 适用条件 | 普通小学家庭 |
| 依据类型 | J：编辑建议 |
| 行动优先级 | 中（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

依据：本项目原创决策建议，无直接效果研究；不包装为循证结论。
