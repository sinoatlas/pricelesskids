### 12-01 · 乘车使用适配儿童约束系统

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 婴儿至适合成人安全带前 |
| 怎么做 | 按车辆、座椅说明及身高体重选择和安装，儿童尽可能反向坐到制造商允许上限；每次检查约束。 |
| 金钱成本 | 必要安全设备费用 |
| 时间与精力 | 安装核对及每次使用 |
| 主要收益 | 降低交通伤害风险 |
| 适用条件 | 乘车儿童 |
| 依据类型 | G：NHTSA技术建议 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 美国机构安全建议不是中国法律门槛；合规认证和当地法规另核，不给通用年龄替代产品上限。 |
| 核验日期 | 2026-10-10 |

- [S25: How to Install Rear-Facing Car Seats](https://www.nhtsa.gov/car-seats-and-booster-seats/how-install-rear-facing-car-seats) — 官方检索正文已读；适用范围：交通安全技术参考；非中国法规。

### 12-02 · 二手安全设备不能只看便宜

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 儿童 |
| 怎么做 | 来源不明座椅不使用；核对事故史、有效使用期限、型号、召回、配件、说明书和制造商要求。普通衣物和图书另看卫生与完整。 |
| 金钱成本 | 可靠设备实际报价 |
| 时间与精力 | 一次核对 |
| 主要收益 | 避免无法识别的结构风险 |
| 适用条件 | 考虑二手儿童座椅家庭 |
| 依据类型 | G+J：官方清单与编辑选择 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

### 12-03 · 水边看护始终近距离

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—6岁 |

| 主要收益 | 减少溺水危险 |

| 依据类型 | G+J：托育指南及家庭应用 |
| 行动优先级 | 极高（编辑判断） |

### 12-05 · 成人参加正规的急救训练

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 全阶段 |
| 怎么做 | 向当地红十字会、正规医疗培训机构核实儿童心肺复苏和气道异物训练；学会呼救和AED定位，定期复训。 |
| 金钱成本 | 按培训公示；可能有公益班 |
| 时间与精力 | 实际课程时长 |
| 主要收益 | 提高应急准备 |
| 适用条件 | 照护者和有能力青少年 |
| 依据类型 | J：编辑建议 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 本指南不写未经验证的急救步骤；不能将网络阅读视为实操能力。 |
