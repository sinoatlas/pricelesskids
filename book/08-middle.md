# 12—15岁：中考、学籍和路径选择

江苏中考由各市组织；总分、指标生、体育和报名资格不能写成全省一个标准。

### 08-01 · 初一就查指标生与转学影响

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 12—15岁 |
| 怎么做 | 问学校及教育局本地指标或分配生条件，尤其本校连续就读、学籍、应届身份和跨区转学影响；保存当年文件。 |
| 金钱成本 | 0元核对 |
| 时间与精力 | 初一及变更前 |
| 主要收益 | 避免失去符合条件的招生机会 |
| 适用条件 | 考虑转学或择校家庭 |
| 依据类型 | P+J：无锡案例与核查建议 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 无锡部分条件不是全省统一规则；不推导所有初中必须读满三年才可中考。 |
| 核验日期 | 2026-10-10 |

- [C03: 2026无锡市区义务教育招生意见](https://www.wuxi.gov.cn/doc/2026/05/07/4772332.shtml) — 官方正文已读；适用范围：无锡市区；江阴宜兴另核。

### 08-02 · 做一张本市中考规则表

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 12—15岁 |
| 怎么做 | 记录科目总分、体育、实验、听说、综合素质、报名资格、志愿批次及截止；每学年以本市最新文件更新。 |
| 金钱成本 | 0元 |
| 时间与精力 | 每年约一小时，编辑估计 |
| 主要收益 | 减少高成本程序错误 |
| 适用条件 | 所有初中家庭 |
| 依据类型 | J：编辑核查方法 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

### 08-03 · 体育准备融入全年活动

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 12—15岁 |
| 怎么做 | 按本市项目和医生建议，渐进练习基础体能与技能；有伤病核实免缓考规定，不在临考前强行加量。 |
| 金钱成本 | 普通器材或校内资源 |
| 时间与精力 | 日常规律活动 |
| 主要收益 | 兼顾健康和考试准备 |
| 适用条件 | 适合运动的学生 |
| 依据类型 | G+J：活动指南与备考安排 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 考试分数规则不由WHO规定；具体病情和运动禁忌由医生判断。 |
| 核验日期 | 2026-10-10 |

- [S18: WHO guidelines on physical activity and sedentary behaviour](https://iris.who.int/bitstream/handle/10665/336656/9789240015128-eng.pdf) — 指南PDF检索正文已读；适用范围：5—17岁及其他年龄组。

### 08-04 · 普高、中职、五年制高职分别核对

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 14—15岁 |
| 怎么做 | 对比招生计划、学籍类型、学费、毕业证、升学考试、实习和转段条件；从主管部门及校方正式文件确认。 |
| 金钱成本 | 按学校公示和全过程成本 |
| 时间与精力 | 一次对比及学生讨论 |
| 主要收益 | 保留适合学生的教育路径 |
| 适用条件 | 中考志愿阶段 |
| 依据类型 | J：路径比较建议 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 不承诺“中职必升本”“五年制高职就是本科”；具体项目每年另核。 |
| 核验日期 | 2026-10-10 |

- [S05: 江苏省学生资助政策简介（2025年版）](https://jyt.jiangsu.gov.cn/art/2025/4/29/art_60306_11555460.html) — 官方检索正文可读；年度标准需复核；适用范围：江苏各学段符合条件学生。
- [S30: 江苏2026年普通高考报名问答（四）](https://www.jseea.cn/webfile/index/index_zkxx/2025-11-03/7390995624633569280.html) — 官方检索正文已读；适用范围：报考江苏2026高考者。
