### 14-01 · 将儿童支出分成五本账

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 全阶段 |
| 怎么做 | 分别记必要生活、教育照护、健康保障、可选体验、应急与机会成本；储蓄和贷款单列，不与消费重复计入。 |

### 14-02 · 基础医保先落实，商业保险读条款

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 出生至大学 |
| 怎么做 | 先确认基本医保；如需商业保障，逐条比免责、等待期、续保、限额、已有病史及家庭保费承受能力。 |
| 金钱成本 | 保费按报价 |
| 时间与精力 | 一次对比及年度复核 |
| 主要收益 | 避免买了仍不覆盖关键风险 |
| 适用条件 | 有额外保障需求家庭 |
| 依据类型 | J：条款核查方法 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 不推荐具体产品，不以收益预测销售储蓄保险；如实健康告知，理赔依据合同。 |
| 核验日期 | 2026-10-10 |

- [S02: 江苏省贯彻落实基本医疗保险参保长效机制的若干举措](https://ybj.jiangsu.gov.cn/art/2025/6/30/art_74036_11604136.html) — 官方正文已读；适用范围：江苏居民医保。

### 14-03 · 课包按监管限额和合同支付

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 3岁以上校外培训 |
| 怎么做 | 核实资质、合同和监管账户；预收费时间不超3个月或60课时，非学科类一次不超5000元；留发票和退费条款。 |
| 金钱成本 | 实际价格；限额不是建议花满 |
| 时间与精力 | 购买前核对 |
| 主要收益 | 降低跑路和退费风险 |
| 适用条件 | 校外培训家庭 |
| 依据类型 | P：教育部消费提示 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 学科类另受政府指导价和培训时间等规则约束；短期付款也不保证机构安全。 |
| 核验日期 | 2026-10-10 |

- [S27: 校外培训有风险，报班需谨慎](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202303/t20230313_1050700.html) — 官方检索正文已读；适用范围：中小学生校外培训。

### 14-06 · 长期教育钱与应急钱分开
