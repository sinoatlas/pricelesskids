### 10-01 · 困难新生先咨询绿色通道

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 大学入学 |
| 怎么做 | 收到录取通知后联系校资助中心，询问绿色通道、认定、助学金、贷款、应急补助和勤工助学。 |
| 金钱成本 | 先核实资助后做现金计划 |
| 时间与精力 | 暑期及入学期间 |
| 主要收益 | 避免因现金不足放弃入学 |
| 适用条件 | 家庭经济困难新生 |
| 依据类型 | P+J：资助政策与咨询建议 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

### 10-02 · 助学贷款只贷需要的金额

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 大学 |
| 怎么做 | 本专科每年最高20000元、研究生25000元；优先支付学费住宿，余额可补生活。查看合同、贴息与还款，不与消费贷混用。 |
| 金钱成本 | 本金需还；在校贴息按规定 |
| 时间与精力 | 申请及每年核对 |
| 主要收益 | 缓解必要教育现金压力 |
| 适用条件 | 符合国家助学贷款条件学生 |
| 依据类型 | P：2026省通知 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 上限不是人人必贷金额；不能把贷款当收入或无偿补贴。毕业后的利息及还款按合同和当年政策。 |
| 核验日期 | 2026-10-10 |

- [S06: 2026年国家助学贷款工作指引转发通知](https://jyt.jiangsu.gov.cn/art/2026/5/8/art_58960_11767042.html) — 官方正文已读；适用范围：符合条件本专科及研究生。

### 10-03 · 大学医保衔接先确认再缴费

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 大学入学与毕业 |
| 怎么做 | 问学校医保属于何统筹区、待遇起止、寒暑假就医和异地结算；家庭所在地同时有保时先核实，避免重复参保。 |
| 金钱成本 | 实际个人缴费 |
| 时间与精力 | 入学、每年及毕业前 |
| 主要收益 | 减少保障空窗及重复费用 |
| 适用条件 | 所有大学生 |
| 依据类型 | P+J：医保连续参保与衔接建议 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 不臆造13市统一保费或报销率；就业和身份转换按实际参保地规则。 |
| 核验日期 | 2026-10-10 |

- [S02: 江苏省贯彻落实基本医疗保险参保长效机制的若干举措](https://ybj.jiangsu.gov.cn/art/2025/6/30/art_74036_11604136.html) — 官方正文已读；适用范围：江苏居民医保。

### 10-04 · 电脑按课程需求采购

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 大学 |
| 怎么做 | 先问专业软件、性能和机房资源，再查合规优惠及售后；已有设备满足需求先用，不因入学统一换旗舰机。 |
| 金钱成本 | 按需求报价 |
| 时间与精力 | 一次课程需求核对 |
| 主要收益 | 减少过度配置与闲置 |
| 适用条件 | 有设备需要学生 |
| 依据类型 | J：消费建议 |
| 行动优先级 | 中（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |
