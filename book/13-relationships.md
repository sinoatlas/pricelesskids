### 13-01 · 减少打骂，学习可持续养育方法

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—17岁 |
| 怎么做 | 遇到冲突先确保安全，成人暂停升级冲突；寻求可验证的正向养育课程或专业支持，用明确边界与回应替代羞辱。 |

### 13-03 · 危险时先急救，热线作支持

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 全阶段 |
| 怎么做 | 出现自伤危险、现实暴力或生命危险时不让孩子独处，及时联系120/110等急救；心理援助可拨12356并核实时段。 |
| 金钱成本 | 按实际通话和救助 |
| 时间与精力 | 需要时立即 |
| 主要收益 | 连接紧急及心理支持 |
| 适用条件 | 遇到危机家庭 |
| 依据类型 | P+J：热线与编辑危机原则 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 12356不代替急诊或警方；本指南不提供远程诊断。 |
| 核验日期 | 2026-10-10 |

- [S22: 关于应用12356全国统一心理援助热线的通知](https://www.nhc.gov.cn/yzygj/c100068/202412/49a1a65386cd4be582d4702fd0926ee8.shtml) — 官方检索正文已读；适用范围：全国。

### 13-05 · 数字设备使用共同定规则
