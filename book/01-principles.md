# 先定原则：把钱和时间花在关键处

性价比指用可承担的资源保护健康、安全、关系和选择机会。孩子不是投资标的，不计算孩子的“回报率”。

### 01-01 · 先保健康安全，再谈排名

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 全阶段 |
| 怎么做 | 把医保、基本照护、安全设施、睡眠和家庭关系列为底线；其余项目按孩子需求和家庭能力排序。 |
| 金钱成本 | 先保障必要支出 |
| 时间与精力 | 每季共同复盘一次 |
| 主要收益 | 减少因攀比挤占关键支出 |
| 适用条件 | 所有家庭 |
| 依据类型 | J：编辑决策框架 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

依据：本项目原创决策建议，无直接效果研究；不包装为循证结论。

### 01-02 · 比较总成本，而不只比标价

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 全阶段 |
| 怎么做 | 比较学费、接送、餐食、器材、家长工时、退费风险和孩子睡眠损失；两方案用同一时间范围。 |
| 金钱成本 | 无需新增消费 |
| 时间与精力 | 一次约30分钟，编辑估计 |
| 主要收益 | 避免低价项目附带高成本 |
| 适用条件 | 选择托育、学校或兴趣班时 |

| 行动优先级 | 高（编辑判断） |

### 01-03 · 免费公共资源先试用

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—18岁 |
| 怎么做 | 先询问社区儿童保健、图书馆、学校课后服务和官方课程；核实预约、押金、适龄与开放时段。 |
| 金钱成本 | 按当地项目；免费不等于无押金 |
| 时间与精力 | 查询及往返时间 |
| 主要收益 | 降低试错支出 |
| 适用条件 | 有可达公共资源家庭 |
| 依据类型 | P+J：服务依据及编辑建议 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

### 01-05 · 给家庭设可退出的试用期限

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 全阶段 |
| 怎么做 | 新兴趣、托育或学习工具先小额短期试用，事先约定观察什么、何时停止；保留孩子反馈。 |
| 金钱成本 | 由试用报价决定 |
| 时间与精力 | 每次复盘约15分钟，编辑估计 |
| 主要收益 | 保留预算和时间弹性 |
| 适用条件 | 非医疗、非必须项目 |
| 依据类型 | J：编辑建议 |
| 行动优先级 | 中（编辑判断） |
