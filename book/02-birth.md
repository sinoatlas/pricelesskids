# 出生到满月：证件、医保和照护

先建一份私有家庭档案，安排出生后医疗、证件和照护。不要把个人证件上传本仓库。

### 02-01 · 把新生儿医保办在90天内

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 出生0—90天 |
| 怎么做 | 出生后尽快向当地医保核实登记及缴费，保存到账记录；需要出生当年报销的，确认所缴年度。 |
| 金钱成本 | 当地个人缴费标准 |
| 时间与精力 | 线上办理及可能补材料 |
| 主要收益 | 符合条件可从出生日起享受待遇 |
| 适用条件 | 江苏居民医保新生儿 |
| 依据类型 | P：省政策 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 出生90天内含第90天；仅在集中期缴下一年度的，下一年1月1日起享受。缴费到账与所缴年度都重要。 |
| 核验日期 | 2026-10-10 |

- [S02: 江苏省贯彻落实基本医疗保险参保长效机制的若干举措](https://ybj.jiangsu.gov.cn/art/2025/6/30/art_74036_11604136.html) — 官方正文已读；适用范围：江苏居民医保。

### 02-04 · 低龄发热先联系医生

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 3个月及以下 |
| 怎么做 | 发现发热及时联系儿科；AAP对3个月及以下婴儿直肠温度达到38°C建议立即联系医生。告知测温部位与精神、吃奶情况。 |
| 金钱成本 | 就诊成本 |
| 时间与精力 | 立即处理 |
| 主要收益 | 避免漏掉低龄严重感染 |
| 适用条件 | 低龄婴儿；家长不熟悉直肠测温时请医护指导 |
| 依据类型 | G：专业机构建议 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 不能把直肠38°C机械换成所有测量部位的阈值；不提供家庭直肠测温操作。呼吸困难、难唤醒等急症立即急救。 |
| 核验日期 | 2026-10-10 |

- [S35: Fever and Your Baby](https://www.healthychildren.org/english/health-issues/conditions/fever/pages/fever-and-your-baby.aspx) — 专业机构检索正文已读；适用范围：婴幼儿；测量方法有差异。
