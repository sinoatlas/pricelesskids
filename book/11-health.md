# 全阶段健康：眼睛、牙齿、运动与就医

公共健康建议有适用条件。疾病、残障、早产等需要个体计划；不要为省钱延迟评估。

### 11-01 · 用好0—6岁公共儿童保健

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 0—6岁 |
| 怎么做 | 在常住地社区卫生服务中心或乡镇卫生院问建档和预约，按时接受基础健康管理；官方答复提到13次免费检查。 |
| 金钱成本 | 基础公卫免费；其他检查另核 |
| 时间与精力 | 预约及往返 |
| 主要收益 | 连续监测生长发育 |
| 适用条件 | 辖区0—6岁儿童 |
| 依据类型 | P：国家公卫服务 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 免费次数不等于所有商业体检或专科治疗免费。迁居时需确认档案衔接。 |
| 核验日期 | 2026-10-10 |

- [S11: 0—6岁儿童健康管理相关提案答复](https://www.nhc.gov.cn/wjw/tia/202112/47fc2eb490804f5abce88f47a7c42d61.shtml) — 官方检索正文已读；适用范围：辖区0—6岁儿童。

### 11-03 · 日间户外优先排进日程

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 儿童青少年 |
| 怎么做 | 以每日不少于2小时或每周累计14小时为日间户外目标，校内外合计；注意防晒、高温及孩子能力。 |
| 金钱成本 | 公园等可零新增支出 |
| 时间与精力 | 真实占用时间，可与活动合并 |
| 主要收益 | 有助于近视防控 |
| 适用条件 | 一般儿童青少年 |
| 依据类型 | G：官方健康建议；R为研究旁证 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 不许诺不近视或逆转近视；研究设计、地区和年龄不能直接预测个体收益。 |
| 核验日期 | 2026-10-10 |

- [S16: 防控儿童青少年近视核心知识十条](https://www.nhc.gov.cn/fys/c100078/202307/a210193cfd774009a1db0399d713fec9.shtml) — 官方检索正文已读；适用范围：儿童青少年。

### 11-04 · 异常视力请眼科评估

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 全阶段 |
| 怎么做 | 保留视力和屈光记录；眯眼、看不清或筛查异常时就诊，验光、眼轴及控制方案依医嘱，不买“恢复视力”承诺。 |
| 金钱成本 | 门诊及必要矫正费用 |
| 时间与精力 | 按医嘱复诊 |
| 主要收益 | 避免误配与延误 |
| 适用条件 | 有视力问题儿童 |
| 依据类型 | G+J：官方近视知识与行动建议 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

- [S16: 防控儿童青少年近视核心知识十条](https://www.nhc.gov.cn/fys/c100078/202307/a210193cfd774009a1db0399d713fec9.shtml) — 官方检索正文已读；适用范围：儿童青少年。

### 11-05 · 牙齿清洁和恒磨牙评估一起做

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 长牙后至大学 |
| 怎么做 | 按牙医指导用适龄含氟牙膏与合适用量，家长帮助清洁；恒磨牙萌出后评估窝沟封闭，问当地是否有公益项目。 |
| 金钱成本 | 基础用品；专业项目按当地 |
| 时间与精力 | 每天清洁及定期检查 |
| 主要收益 | 预防龋齿及及早处理 |
| 适用条件 | 适龄儿童；用氟有个体及地区条件 |
| 依据类型 | G：官方口腔指南 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 不提供通用氟剂量；窝沟封闭有适应证，不替代刷牙，公费项目不是全省一律免费。 |
| 核验日期 | 2026-10-10 |

- [S19: 儿童龋病预防干预技术实施方案](https://www.nhc.gov.cn/jkj/c100063/201907/aebd8901fe284b6bacb45da8dfa1a0c7/files/1733138021538_65291.pdf) — 官方PDF检索正文已读；适用范围：符合口腔预防适应证儿童。
- [S20: 中国居民口腔健康指南](https://www.nhc.gov.cn/wjw/jkshfs/200909/058b3e9ade454a3f9f8bfe807ae78aaa.shtml) — 官方检索正文已读；用量交专业核对；适用范围：口腔健康；儿童用量依当下牙医指导。

### 11-06 · 睡眠与运动不被补课挤走

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 6—17岁 |
| 怎么做 | 参考小学10小时、初中9小时、高中8小时睡眠；5—17岁一周平均每天至少60分钟中高强度活动，按能力渐进。 |
| 金钱成本 | 可用日常活动 |
| 时间与精力 | 每天持续安排 |
| 主要收益 | 支持身心健康和生活节律 |
| 适用条件 | 一般儿童青少年 |
| 依据类型 | G：官方及WHO建议 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 户外、运动可重叠，不能直接相加成每天必须额外3小时；有疾病或伤病先个体评估。 |
| 核验日期 | 2026-10-10 |

- [S17: 儿童青少年近视防控适宜技术指南（更新版）](https://www.nhc.gov.cn/jkj/c100062/202110/a05ccaf5773a436486d2d79b59c0a5e9.shtml) — 官方检索正文已读；适用范围：儿童青少年。
- [S18: WHO guidelines on physical activity and sedentary behaviour](https://iris.who.int/bitstream/handle/10665/336656/9789240015128-eng.pdf) — 指南PDF检索正文已读；适用范围：5—17岁及其他年龄组。
