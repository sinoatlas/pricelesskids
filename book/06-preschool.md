# 3—6岁：幼儿园、入学准备与费用

选择可达、合规、照护稳定的园，查看真实收费表；不把提前学小学课程当唯一准备。

[返回目录](../README.md) · [核验方法](../docs/methodology.md) · [来源台账](../docs/sources.md)

### 06-01 · 先比较公办与普惠园总价

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 3—6岁 |
| 怎么做 | 取得保教、伙食、延时、托育及其他收费公示；核实普惠身份、适龄、距离、招生和请假退费。 |
| 金钱成本 | 按园公示逐项相加 |
| 时间与精力 | 一次核价及实地了解 |
| 主要收益 | 避免只看月保教费 |
| 适用条件 | 江苏在园或择园家庭 |
| 依据类型 | P+J：省收费管理解读 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

- [S08: 江苏省幼儿园收费管理办法政策解读](https://fzggw.jiangsu.gov.cn/art/2026/9/4/art_314_11826305.html) — 官方正文已读；适用范围：江苏幼儿园。

<a id="06-02"></a>

### 06-02 · 学前一年免保教费要核清范围

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 通常大班学前一年 |
| 怎么做 | 公办学前一年保教费免除，民办按政策给予相应减免；确认园所的减免金额、名单及账单。 |
| 金钱成本 | 只扣实际减免部分 |
| 时间与精力 | 缴费前核对 |
| 主要收益 | 减少符合政策的教育支出 |
| 适用条件 | 符合政策的学前一年在园儿童 |
| 依据类型 | P：2026财政信息确认 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 伙食、住宿、延时等不因此一并免费；民办超出减免标准的部分可能仍需支付。 |
| 核验日期 | 2026-10-10 |

- [S07: 2026年支持学前教育发展资金消息](https://czt.jiangsu.gov.cn/art/2026/5/11/art_8065_11771325.html) — 官方正文已读；适用范围：全国学前一年在园儿童。

### 06-03 · 幼小衔接重生活与适应

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 5—6岁 |
| 怎么做 | 练习表达需要、整理物品、如厕、轮流合作和稳定作息；与园校交流适应困难，不因焦虑一次购买大课包。 |
| 金钱成本 | 可零新增支出 |
| 时间与精力 | 日常练习 |
| 主要收益 | 减少入学生活压力 |
| 适用条件 | 即将入小学家庭 |
| 依据类型 | P+J：学前教育法与编辑建议 |
| 行动优先级 | 高（编辑判断） |
| 边界 / 容易误解处 | 法律规定针对幼儿园小学化；本项目不声称家庭适度识字违法。 |
| 核验日期 | 2026-10-10 |

- [S29: 中华人民共和国学前教育法](https://www.moe.gov.cn/jyb_sjzl/sjzl_zcfg/zcfg_jyfl/202411/t20241108_1161363.html) — 官方检索正文已读；适用范围：全国学前教育。

### 06-04 · 小学年龄和缓学按当地办理

| 字段 | 内容 |
| --- | --- |
| 年龄 / 场景 | 5—7岁 |
| 怎么做 | 查当年招生年龄截止及材料；因身体原因需要缓学时问区县教育局审批手续，勿直接停止报名。 |
| 金钱成本 | 按证明与办理费用 |
| 时间与精力 | 招生季前准备 |
| 主要收益 | 避免误过入学及缓学程序 |
| 适用条件 | 适龄儿童和需要缓学者 |
| 依据类型 | P+J：地方招生文件 |
| 行动优先级 | 极高（编辑判断） |
| 边界 / 容易误解处 | 年度出生日期窗口不能用于未来所有年份；特殊需要儿童按当地安排。 |
| 核验日期 | 2026-10-10 |

- [C01: 2026南京义务教育招生入学问答](https://edu.nanjing.gov.cn/njsjyj/202604/t20260429_5832026.html) — 官方正文已读；适用范围：南京各区；具体施教区看区细则。
- [C02: 2026苏州市区积分入学政策解读](https://www.suzhou.gov.cn/szsrmzf/mszx/202601/a1d7e8383ba149aba542e342215b38a0.shtml) — 官方正文已读；适用范围：苏州市区六区；不套用昆山等县级市。

### 06-05 · 幼儿兴趣班少量体验

| 金钱成本 | 家庭自行设上限 |
| 时间与精力 | 保留自由活动 |
| 主要收益 | 降低不适配和接送负担 |
| 适用条件 | 非必需兴趣培养 |
| 依据类型 | J：编辑建议 |
| 行动优先级 | 中（编辑判断） |
| 边界 / 容易误解处 | 成本与优先级为本项目判断；没有对个体效果作保证。 |
| 核验日期 | 2026-10-10 |

依据：本项目原创决策建议，无直接效果研究；不包装为循证结论。
